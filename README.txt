SOLVE WITH MRS. YOST — MASTER WEBSITE

This is the master website, based on the recovered original design.

FILES
index.html = website layout and interactions
content.json = skill library and lesson content
editor.html = browser-based editor for content.json
assets/ = put your Canva images, PDFs, and other downloadable files here

TO PUBLISH (GitHub Pages)
1. Create a public GitHub repository (e.g., solve-with-mrs-yost).
2. Upload ALL files and the assets folder to the root of the repository.
3. In Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
4. Wait for GitHub to provide the public URL.
5. Keep a local backup of this entire folder/ZIP.

TO ADD A LESSON
1. Open your published editor.html page (or run a local server to open it).
2. Select the skill, fill in fields, click Save, then Download updated content.json.
3. In GitHub, replace content.json with the downloaded version and commit.
4. Upload new PDFs/images to assets/ and use paths such as assets/factoring-intro.png.
5. The site automatically shows your new content and 'Lesson ready' status.

NOTE: editor.html is not password-protected. It only edits files in your browser; it cannot change your live site without GitHub access. Do not put passwords or private student data in content.json.
